# Respuestas de la campaña V4

Conservar las respuestas originales de ChatGPT, Gemini y Claude, una por contrato y repetición. Los seis archivos disponibles del piloto pertenecen a V3 y se guardan en `../../pilot/llms/`.

Cada ejecución debe identificar el contrato, el hash de entrada, el modelo exacto, la interfaz, el modo de razonamiento, la fecha, la versión del prompt y los controles de aislamiento utilizados. Registrar los rechazos y cualquier dato no observable como tal, sin estimarlo.

`run_template.json` sirve como ficha inicial; `../../analysis/registro_ejecuciones_v4.csv` reúne el índice de ejecuciones y las rutas de respuesta.
